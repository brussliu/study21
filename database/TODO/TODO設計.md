## 1. 画面の考え方（2.0 との違い）

| | 2.0（todo.jsp） | 2.1（作り直し） |
|---|---|---|
| 一覧 | 表のみ。作成者は列、チェックボックスで一括完了 | **一覧／カレンダーのタブ**。表は 操作 / タイトル / 優先度 / 期限 / メモ / 状態（**操作は最左・作成者列とチェックボックス列は無し**） |
| 子タスク | 親の行に常に展開して並べる | **折りたたみ**（既定は閉じる）。親タスクの見出し自体が開閉ボタンで、表示は **「タイトル 完了/全体」**（例: `ハリポタ 0/17`）。開くと親と同じ列に子タスクの行が並ぶ。見出しの【すべて展開／すべて折りたたむ】で表示中の行をまとめて開閉できる |
| 子タスクの操作 | （無し） | 一覧の子タスク行からも**状態を 1 つ進められる**（親と同じアイコン。未着手→進行中→完了→未着手） |
| 検索条件 | 一覧と同じカード（ラベル付きの行） | **一覧カードの見出し行にまとめる**（バッチ実行履歴と同じ形。ラベルは置かず `aria-label` と placeholder で意味を持たせ、`btn--sm` の【検索】【リセット】を右端に置く。状態・優先度・完了も表示は変更した時点で検索する） |
| 状態の変更 | 一括完了ボタン | **1 行 1 アイコン**（未着手→`play` / 進行中→`check-circle` / 完了→`rotate`）。押すたびに 未着手→進行中→完了→未着手 |
| 子どもの入力 | 1 件ずつ追加 | **Excel 風グリッド**（NO 連番・行追加・行削除・クリックで選択／ダブルクリック・`F2` で入力／方向キーで移動）＋ **Excel からの貼り付け** |
| 保護者 | 自分の TODO のみ | 「**お子さまの TODO にも登録する**」で、同じ内容を子どもの持ち物としても作れる |

```
[タブ] 一覧 / カレンダー            [未着手 n] [進行中 n] [完了 n]   [＋ 新規]
[一覧カードの見出し]
  TODO一覧  全 n 件  [キーワード] [状態▾] [優先度▾] [☑完了も表示] [検索] [リセット] [▸ すべて展開]
  操作 | タイトル | 優先度 | 期限 | メモ | 状態
  ▸ ハリポタ 0/17                          高  2026/9/20  …  未着手
  ▶   （子タスクの行。タイトルは 2 文字ぶん下げる。ツリー記号は使わない）
      問1〜3                              中  —           …  未着手
[カレンダー] 期限日ごとに 未着手・完了の件数。日付クリック＝その日を期限に新規作成
```

検索条件の見た目は `views/batch/BatchHistoryView.vue`（バッチ実行履歴）に合わせる:
見出し行の右側に `margin-left: auto` で並べ、1 行に収める（設計システムの `.input` / `.select` は
`width: 100%` なので、`.todo-filters` の中で `width: auto` にして中身に合わせて縮める）。
幅が足りないときは見出し行ごと次の行に落ちる。

### 新規／編集ダイアログの形

- 上部の 4 項目（タイトル・メモ・優先度・期限）は **タイトルとメモを 1 行まるごと**使い、
  **優先度と期限を同じ行**に 2 列で並べる。
  並びは CSS グリッド（`.todo-form` は `grid-template-columns: repeat(2, minmax(0, 1fr))`、
  `.todo-field--full` だけ 1 行まるごと）で、**項目どうしの間隔は `gap: var(--sp-4)`（16px）**にして
  行間を広めに取る（以前はスタイルを持たず、既定の詰まった並びだった）。
- 「子タスク」の見出しは **上の項目（タイトル・メモ）と同じ左端**に揃える（字下げしない）。
  設計システムの `.table-section__head` は左右に余白を持つので使わず、
  ダイアログ用の `.todo-grid__head` を使う（行追加ボタンは右端に置く）。
- 子タスクの**行削除アイコン（×）は赤**（`.icon--danger`。危ない操作だと分かるように）。
- **列の幅はドラッグで変えられる**（タイトル / 優先度 / 期限 / メモ）:
  - 見出しの右端のつまみ（`.todo-grid__resizer`）をドラッグすると、**左右の列で幅をやり取り**する
    （合計は変えないので表の幅は動かない）
  - 幅は `<colgroup>` の **％**で持つ（× 5% / NO 6% / 4 列で 89% = 100%）。
    最小は 8%（これ以上は狭くできない）
  - つまみはキーボードでも動かせる（`←→` で 1%、`Shift` で 5%）。**ダブルクリックで既定に戻る**
- 子タスクは **表計算のように入力する**（`/vol5/1000/DATA0/work/IRJ/functionManagement.jsp` の
  「入力項目定義 / 出力項目定義」を参照）:
  - 罫線・行の高さ・ヘッダーの色を Excel に寄せる。**入力欄は編集するセルにだけ出す**
  - **クリック＝選ぶだけ**（入力欄は出ない。値はテキストで出る）。緑の枠で選択を示す
  - **ダブルクリック / `F2`＝入力**（そのセルだけ入力欄になり、フォーカスが入る。
    タイトル・メモは文字が全選択されるので、そのまま打ち替えられる）
  - **`Enter`＝確定して 1 つ下へ**、**`Esc`＝取り消して編集前の値に戻す**、
    `F2` をもう一度押すのも確定。別のセルをクリックしたときも確定する
  - **選択中は `↑↓←→` で隣のセルへ移動**（端では止まる。`Shift`＋方向キーで範囲を広げる）。
    そのために表そのものに `tabindex="0"` を与え、セルをクリックすると表にフォーカスを移す。
    編集中の `↑↓←→` は入力欄の操作なのでセルは動かない
  - ドラッグで範囲選択、`Esc`（選択モード）で選択解除
  - **Ctrl+C** で選択中のセル／範囲を**タブ区切り**でコピー（そのまま Excel に貼り付けられる。
    優先度は `高/中/低`、期限は `YYYY-MM-DD` の形）
  - **Excel からコピーしたタブ区切りは、選択中のセルを左上として貼り付く**（足りない行は自動で増える）。
    セルを選んでいないときは、これまでどおり末尾に行として足す
- 実装: `views/todo/TodoView.vue`（`GRID_COLUMNS` / `gridCursor` / `gridEditing` /
  `startGridEdit` / `commitGridEdit` / `cancelGridEdit` / `onGridKeydown` / `copyGrid` / `pasteGrid`）と
  `features/todo/todo.css`（`.todo-grid` の Excel 風スタイル・`.todo-grid__value`）。

### 折りたたみの決めごと

- **既定は閉じた状態**。子タスクを持つ行は、見出し自体が開閉ボタンになる
  （`▸ ハリポタ 0/17`。`aria-expanded` を付け、キーボードでも Enter / Space で開閉できる）。
- **表示は「タイトル 完了/全体」**。以前の「子タスク 0/17 タイトル」から変更した（ユーザーの指定）。
- 開くと子タスクは **親と同じ 6 列**（操作 / タイトル / 優先度 / 期限 / メモ / 状態）の行として並ぶ。
  タイトルは親より **2 文字ぶん右**にずらす（`padding-left: calc(var(--sp-2) + 2ch)`）。
  ツリー記号（`├` `└`）は使わない。
- 子タスク行の左端には**状態を進めるアイコン**を置く（親と同じ動き・同じ色）。
  子タスクの状態は `POST /api/user/todos/{id}/status` で更新する（親の集計 `0/17` もすぐ反映される）。
- 実装: `views/todo/TodoView.vue`（`expandedIds`）／`features/todo/todo.css`（`.todo-toggle`・`.todo-child-row`）。
  確認は `tests/todo.spec.ts`（28 件）・`tmp/e2e/e2e-todo-ui.mjs`（35 項目）・
  `tmp/e2e/e2e-todo-create.mjs`（23 項目）・`tmp/e2e/e2e-todo-grid.mjs`（54 項目）。

## 2. 子タスクの入力（Excel 風グリッド）

- 列は **NO / タイトル / 優先度 / 期限 / メモ**（先頭は行削除の ×。NO は自動連番）。
- 行追加で 1 行増やし、× で削除する。保存時は**タイトルが空の行を捨てる**。
- **クリックでは編集に入らず、そのセルが選ばれるだけ**（緑の枠。値はテキストで表示）。
  **ダブルクリックか `F2`** で入力欄を出し、**`Enter` で確定して下へ／`Esc` で取り消し**。
  選択中は **`↑↓←→` で移動**する（編集中の矢印は入力欄の操作）。
- ドラッグで範囲選択、`Esc`（選択モード）で選択解除する。
- **コピー**: `Ctrl+C` で選択中のセル／範囲をタブ区切りにしてクリップボードへ入れる
  （そのまま Excel に貼り付けられる。優先度は `高/中/低`、期限は `YYYY-MM-DD`）。
  入力中の文字を選んでいるあいだは、ブラウザ既定のコピーに任せる。
- **貼り付け**: タブ区切りテキストを取り込む（列の順番は タイトル / 優先度 / 期限 / メモ）。
  **セルを選んでいれば、そのセルを左上として流し込む**（足りない行は自動で増える）。
  選んでいないときは末尾に行として足す（初期状態の空行 1 行だけのときは置き換える）。
  空行は無視する。
- 値の正規化: 優先度は `高/中/低`・`HIGH/NORMAL/LOW`・`H/M/L` を受け付け、
  期限は `2026/9/21`・`2026-9-21`・`2026-09-21` を受け付ける（解釈できない値は空にする）。
- 参考にした画面: ユーザー指定の `/vol5/1000/DATA0/work/IRJ/functionManagement.jsp`
  （`<table class="excel-table">`＋行追加＋`onpaste` の TSV 取込＋範囲コピー）。
  見た目は同ページの `assets/css/excel-table.css`（罫線・行の高さ・ヘッダー・選択色）に寄せ、
  色は 2.1 の `tokens.css` の変数に置き換えている。

## 3. データ

- 1 行 = `COM_TODO情報` 1 件。**親子は `親TODOID` の自己参照**（子タスク専用の表は作らない）。
- 持ち主は `アカウントID`（`ACC_アカウント` への FK）。保護者が代理で作った TODO も
  **持ち主は子ども**で、作った人は `作成者アカウントID` に残す（一覧の列には出さない）。
- 状態は `TODO`（未着手）/ `DOING`（進行中）/ `DONE`（完了）。2.0 の `O/C/X/D` から移行した。
- 完了には `実施完了日時` が必要（CHECK）。未着手へ戻すと `実施開始日時`・`実施完了日時` を消す。
- **状態の変更も `バージョン` で楽観ロックする**: 一覧が持っている `version` を
  `POST /todos/{id}/status` に一緒に送り、**別の画面で先に更新されていたら 409**
  （「他の操作で先に更新されました。再読み込みしてください。」）にする。
  編集（`PUT`）と同じ扱い。
- 親を完了にすると**子タスクもまとめて完了**になる（子を 1 件ずつ更新する）。

## 4. ロール

**2.1 は当面ロールで機能を分けない**（ユーザーの指定。`docs/SECURITY_AND_ROLES.md` §2.1）。
TODO はログインしていれば誰でも自分の TODO を扱える（学生で検証する）。

| 操作 | 学生 | 保護者 | 管理者 |
|---|---|---|---|
| 自分の TODO の閲覧・作成・編集・削除・状態変更 | 可 | 可 | 可 |
| 子どもの TODO の代理作成（「お子さまの TODO にも登録する」） | – | 可 | – |

- 代理作成は**ロールではなく親子の紐付け**で決まる操作（`alsoForStudent`）。
  サーバ側で `AccountMapper.findStudentByGuardianId` から子どもの `アカウントID` を引き当て、
  紐づいていなければ 400。学生の画面にはチェックボックスを出さない（子どもがいないため）。

## 5. 今回の範囲外

| 対象 | 補足 |
|---|---|
| 一括完了（2.0 のチェックボックス＋一括完了） | **1 行 1 アイコン**の状態変更に置き換えた。API（`POST /todos/complete`）と
  `TodoBulkCompleteRequest` の残骸は使っていないので消してある |
| 繰り返し TODO | 2.0 にも無い |
| 保護者から子どもの既存 TODO の編集・削除 | 今は自分の持ち物のみ（代理作成だけ可能） |
| 通知・リマインド | 期限切れは赤字（`todo-due--overdue`）で示すだけ |

子タスクの操作は**一覧から状態を 1 つ進められる**ほか、親の編集ダイアログ（子タスクのグリッド）で
タイトル・優先度・期限・メモを編集でき、行を消せば削除になる（親タスク単位ではない）。
