# 英語穴埋め問題・英語読解／精読の画面確認用 Demo

## 対象と前提

2.0 の `english_cloze.jsp`・`js/english_cloze.js`、`english_reading_intensive.jsp`・`js/english_reading_intensive_demo.js` を参照した画面設計用の実装。
対象はフロントエンドのみ。API、DB、実際の OCR・AI 解説生成には接続しない。Pinia のメモリ内データは同じタブで共有し、ページ再読み込みで初期化する。
一覧の上部は検索条件から始め、パンくず・装飾用ページ見出し・Demo バナーは置かない。画像取込と生成の説明は編集画面に表示する。

## 画面と操作

`{area}` は `admin` / `student` / `parent`。各エリアの同名メニューから利用できる。

| 機能 | URL（`/{area}/` 以下） | 確認できる内容 |
|---|---|---|
| 穴埋め一覧 | `english-cloze` | ラベルを入力欄の左側に置いた1行の検索条件（問題文・知識点・メモ・出典、種別／名称／年度／元答案の正誤／解説状態）、登録日ソート、20／50／100件のページング。検索操作の横に新規作成・スキャン履歴・検索結果のAI解説生成。操作列に2行配置のAI解説生成（ロボット）・再挑戦・学習ダイアログ・設問削除。再挑戦列に正解／不正解の回数を分けて表示 |
| 穴埋め登録・編集 | `english-cloze/new`、`english-cloze/{id}/edit` | 出典情報、画像取込、ページ単位OCR、設問／選択肢／元答案／正解／知識点／日中解説の修正、解説生成の表示例、保存・キャンセル |
| 穴埋め学習 | 一覧内ダイアログ（直接URL：`english-cloze/{id}/{questionId}`） | 一覧では画面遷移せず表示。設問切替、日中訳、選択肢・正誤・解説、誤答の理由、答案ロック解除と修正、原本、再挑戦・履歴 |
| スキャン履歴 | 穴埋め一覧内のダイアログ | 日時・出典・画像・問題数・結果、原本画像表示。OCRを実行した時点で履歴に残る |
| 精読一覧 | `english-reading-intensive` | タイトル・出典・テーマ・メモの検索、出典／年度／対象級／処理状態の絞り込み、登録日ソート、ページング、語数・設問数・工程進捗・再挑戦回数、削除 |
| 精読登録・編集 | `english-reading-intensive/new`、`english-reading-intensive/{id}/edit` | タイトル・出典・級・難易度・テーマ・メモ、文章／設問／その他の画像分類、文章のみ／図表込み、OCR・導読・逐句解説／語彙・設問解析の4工程、個別実行／再試行／全実行、OCR本文・設問・導読の修正 |
| 原文精読 | `english-reading-intensive/{id}` | 原文精読／設問解析／重点語彙の3タブ。日中切替、訳文表示、文字サイズ、本文／単語の読上げ、原本画像、段落の役割、逐句の訳・文法、導読・要点、学習メモ |
| 設問解析 | 精読画面のタブ | 元答案・正解・選択肢別解説、誤答の振り返り、根拠をクリックして本文の該当文へ移動、答案の修正 |
| 重点語彙 | 精読画面のタブ・詳細ダイアログ | 発音・意味・用例・使用上の注意、単語／熟語・初級／中級・書籍を指定して既存の英語勉強 Demo に登録 |
| 再挑戦 | 一覧・詳細内のダイアログ | 穴埋めは1問、精読は教材の全問。本文／原本と回答、設問移動、回答数、未回答チェック、採点・解説・履歴。回答途中の破棄確認 |

## 状態と境界

- 元の学生答案と再挑戦答案は分離。再挑戦はその時点の問題文・選択肢・正解を複写して記録する。後から元答案を修正しても過去の採点結果は変えない。
- 編集画面は教材のコピーを編集する。保存前の一覧・学習画面には反映しない。未保存で移動する際は破棄を確認する。
- 原本画像の変更はOCR以降、OCR本文・設問の変更は導読以降を未確認に戻す。工程は前の工程が完了した場合だけ実行できる。処理中の二重実行は禁止。
- OCRの再実行は手修正を置き換えるため確認する。工程の再実行では下流工程を未実行に戻す。
- 入力画像は PNG／JPEG／WebP、1枚15MB以内・20枚以内。アップロード、ドラッグ、貼付、一時ファイルのサンプル選択、並べ替え、削除、回転・切抜が可能。ファイルをサーバーへ送信しない。
- 正解が未確定の設問は再挑戦できない。設問は問題文・2～6個の選択肢を使用し、空欄・重複選択肢は保存時に検出する。
- 削除は確認ダイアログを経由し、背景クリックではダイアログを閉じない。
- サンプルには生成済み教材とOCRエラー教材を用意し、完了状態だけでなく再試行の流れも確認できる。

## 実処理へ移行する際の確認事項

画面の承認後に、教材・原本・設問・工程結果・学習履歴・単語帳の関係と保存範囲をDB設計で定める。OCR／AIの出力形式、権限、長時間処理の進捗取得、実ファイル保管、削除と履歴保持の方針もその段階で決める。この変更ではDB定義を作成しない。
