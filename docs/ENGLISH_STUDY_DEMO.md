# 英語勉強の単語・熟語デモ

## 対象と参照

2026-09-27 の依頼に基づくフロントエンド専用デモ。正式 API や DB への保存は行わない。
2.0 の `testword.jsp`・`testword2.jsp`・`phrase_test.jsp`・`word.jsp`・`word_status.jsp` と
各テスト画面を機能の参照元にし、2.1 の日本語勉強と同じ検索・一覧・操作・ダイアログの形式を使う。

## メニューと URL

三つのエリア（admin / student / parent）に共通の三階層メニューを表示する。

| メニュー（英語勉強の下） | URL の末尾 | タブ |
| --- | --- | --- |
| 単語勉強 > 単語テスト | testword | 初級編 / 中級編 |
| 単語勉強 > 単語情報管理 | word | 初級編 / 中級編 |
| 単語勉強 > 単語勉強状況 | word-status | 書籍別 / 単語別 |
| 熟語勉強 > 熟語テスト | phrase-test | 初級編 / 中級編 |
| 熟語勉強 > 熟語情報管理 | phrase | 初級編 / 中級編 |
| 熟語勉強 > 熟語勉強状況 | phrase-status | 書籍別 / 単語別 |

旧四画面の URL は維持する。メニューは `menuRegistry.ts`、ルートは
`features/english-study/routes.ts` が定義し、`SidebarMenuItem.vue` が再帰的に描画する。
直接 URL を開いた場合も祖先メニューを展開する。展開中のグループは手動で閉じられる。

## 操作

- テスト：書籍・分類範囲・等級・種別・状態で検索、複数行作成、習得済の除外、
  出題一覧、回答、判定、中断・再開、結果、誤答だけの再テスト、削除。
- 初級は A〜D、中級は A〜F。A は学習カード、B は意味から英語入力、C は音声から英語入力、
  D は英語から意味選択、E は例文の文脈に合う意味選択、F は例文入力。
- 管理：検索、新規登録、編集、削除、意味・発音・例文の詳細、
  お気に入り、習得状態。熟語は標準構文と種別も編集できる。
- 中級の詳細取得はサンプル表示のみ。AI 通信は行わず、操作結果にその旨を表示する。
- 状況：検索対象の語数・学習した語・習得済・正解率、書籍別の習得率、
  語別の A〜F 集計、復習テストの作成と開始。
- 音声はブラウザの Speech Synthesis を使用する。

## 状態と制限

`features/english-study/store.ts` の Pinia ストアを六画面で共有する。
単語/熟語と初級/中級は別のレコードで管理し、回答は該当する語の技能別集計に反映する。
習得済は利用者が明示的に切り替える。A の自己評価は B〜F の正解率に含めない。
作成済みテストは問題のスナップショットを持ち、詞条の編集・削除後も出題内容を保持する。
テスト削除後も技能別累計を保持する。再読み込みでデモ全体が初期状態に戻る。
入力問題は全半角・大文字小文字・連続空白・文末の句読点を正規化して判定する。
意味の同義表現を AI で評価する処理は含まない。

## 検証

`tests/english-study*.spec.ts` はメニュー、レベル切替、検索、データ分離、
回答集計、誤答再テスト、スナップショット保持を確認する。
Chrome のローカル preview 検証とスクリーンショットは `tmp/english-study-browser.mjs` を使用する。
