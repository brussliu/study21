# 単語テスト

Study 2.0 の `japanese_test.jsp`、`japanese_test.js`、`japanese_word_test.js` を機能基準とし、2.1 の日本語勉強テーブルへ接続する。

## 一覧・作成

- 書籍、分類 From／To、種別、状態で検索する。1 ページは 15 件。
- 複数作成は 1〜20 行。数量 0 は条件に合う全語。各行の候補不足は理由付きでスキップし、他の行は保存する。
- 作成直後は CREATED。別ウィンドウで開始すると RUNNING、全語の回答完了で COMPLETED。
- 一覧へフォーカスが戻ると進捗を更新する。削除には確認を表示する。

## 出題

| 種別 | 操作 |
| --- | --- |
| A | 単語詳細・例文・会話などを学習し、学習完了を記録 |
| B | 中国語の意味から日本語表記と読みを入力。最大 3 回で確定 |
| C1 | 漢字から読みを選択 |
| C2 | 音声から漢字を選択 |
| D | 文脈に合う中国語の意味を選択 |
| E | 読みと中国語の意味から漢字を選択 |

選択問題は有効な正解 1 件と誤答 3 件以上を持つ問題から作成し、1 語につき 1 問を保存する。B は表記と読みの技能を別々に更新し、かなの比較では全半角とひらがな・カタカナを正規化する。

前後移動、回答履歴、途中再開に対応する。非表示・非アクティブ中と保存中の時間は計測しない。発音はブラウザーの日本語音声合成を使用するため、利用可能な音声と音質は端末に依存する。2.0 の Google 高音質 TTS 接続は含まない。

## 永続化と API

現行 DB のテスト、出題、学習状態・技能・日次集計を使用する。`出題選択肢JSON` に出題時の内容と選択肢、`回答履歴JSON` に入力・判定・回答時刻を保持する。教材を編集しても作成済み出題の内容は変えない。回答時はテスト行をロックし、確定済み回答の二重加算を拒否する。DB アクセスは MyBatis を通して SQL ログに記録する。

追加 API は `/api/user/japanese/tests/conditions`、`/search`、`/multiple`、`/{testId}/start`。既存の詳細取得・回答・削除 API と併用する。各ユーザーのテストは認証アカウントで所有権を検証する。

## 検証

フロントエンドは型検査・Lint・Vitest・ビルドを実施する。Chrome では一覧、複数作成、A〜E、入力回答、結果、暗色テーマ、狭幅表示を確認する。バックエンドではサービス単体テストと PostgreSQL のトランザクションをロールバックする統合テストで候補抽出・範囲・固定出題・回答履歴・技能更新を確認する。
