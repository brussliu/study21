# Study 2.1 ブラウザ記録（Chrome 拡張機能 / Manifest V3）

Study 2.1 用の Chrome 拡張機能です。2.0 版拡張（`study2/src/main/resources/extension`）の後継で、
次の 2 つの機能を提供します。

1. **Web 閲覧履歴の収集** — ブラウザ上の閲覧イベントを収集し、Study 2.1 のユーザー API へ送信します。
2. **単語帳（ローカル）** — ページ上で選択した単語を右クリックメニューから登録できます。データはブラウザ内にのみ保存します。

ビルドは不要です（npm もバンドラーも使いません）。`chrome://extensions` からそのまま読み込めます。

---

## 1. 動作環境

- Google Chrome（Manifest V3 対応版。Chrome 102 以降を推奨）
- Study 2.1 のユーザー API に接続できること（既定: `http://192.168.0.100:8082`）

## 2. インストール手順

1. この `extension` フォルダを任意の場所に置きます（解凍したフォルダのままで構いません）。
2. Chrome のアドレスバーに `chrome://extensions` を入力して開きます。
3. 画面右上の **「デベロッパーモード」** を **ON** にします。
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. この `extension` フォルダ（`manifest.json` が入っているフォルダ）を選択します。
6. 一覧に「Study 2.1 ブラウザ記録」が表示されれば完了です。ツールバーの拡張機能アイコンからポップアップを開けます。

> 更新したときは `chrome://extensions` の **「更新」**（再読み込み）ボタンを押してください。

## 3. 初期設定

1. Study 2.1 にログインし、**「インターネット利用履歴」→「Web閲覧履歴」** 画面を開きます。
2. 画面に表示される **接続コード** を発行（またはコピー）します。
3. Chrome のツールバーから拡張機能アイコンをクリックし、**「設定を開く」** を押します（または `chrome://extensions` の「詳細」→「拡張機能のオプション」）。
4. 次の項目を入力して **「保存」** を押します。

| 項目 | 内容 |
| --- | --- |
| API の URL | ユーザー API のベース URL。既定は `http://192.168.0.100:8082`（末尾の `/` は自動で除去されます） |
| 接続コード | 上記「Web閲覧履歴」画面で発行したコード。リクエストの `X-Study21-Extension-Token` ヘッダーに付与されます |
| 端末名 | 端末の表示名。既定はブラウザのプラットフォーム名（例: `Win32`）。`LIU-PC` のような分かりやすい名前を推奨 |
| 閲覧履歴を記録する | OFF にするとイベントを収集しません（送信も行いません） |

5. **「接続テスト」** を押すと、端末登録 API を呼び出して接続を確認します。
   - 成功: `接続テスト成功（HTTP 200）: 端末を登録しました`
   - 接続コード誤り: `接続コードが正しくありません（401）`
   - 接続不可: `接続できませんでした: ...`

設定後、ポップアップの「接続状態」が **接続OK** になれば送信できています。

## 4. 機能 1: Web 閲覧履歴の収集

### 収集するイベント

| イベント種別 | 取得元 |
| --- | --- |
| `HISTORY_VISITED` | `chrome.history.onVisited` |
| `TAB_UPDATED` | `chrome.tabs.onUpdated`（`changeInfo.url` があるとき） |
| `TAB_ACTIVATED` | `chrome.tabs.onActivated` |
| `NAV_COMMITTED` | `chrome.webNavigation.onCommitted`（メインフレームのみ） |
| `NAV_HISTORY_UPDATED` | `chrome.webNavigation.onHistoryStateUpdated`（メインフレームのみ） |

- `http` / `https` 以外の URL（`chrome://`、`file://` など）は収集しません。
- 同一の `(eventType, url, tabId)` は **4 秒以内** の再出現を重複として除外します。
- `staySeconds` は「そのタブが最後にアクティブになってから現在までの秒数」です。アクティブでないタブは 0 になります。

### 送信の仕組み

- イベントはまず `chrome.storage.local` の **キュー（`study21.queue`）** に保存します（上限 2000 件。超えた分は古いものから破棄）。
- **100 件** たまったとき、または **1 分ごと** のアラーム（`chrome.alarms`）で送信します。ブラウザ起動時・設定保存時にも送信を試みます。
- 各イベントには `clientEventId`（`crypto.randomUUID()`）を 1 度だけ発行し、キューと一緒に保存します。再送しても同じ ID を送るため、サーバー側で冪等に重複排除できます。
- 送信に失敗した場合はキューを保持し、次回（1 分後のアラームなど）に再送します。データは失われません。
- **接続コードが未設定のあいだは送信しません**（キューに貯めるだけ）。ポップアップに「接続コード未設定」と表示されます。
- 端末識別子 `deviceId` は初回起動時に `chrome-<タイムスタンプ>-<ランダム>` として生成し、以後は再利用します（`study21.deviceId`）。
- インストール時・ブラウザ起動時に端末登録 API を呼び、以後 **5 分ごと** にハートビートを送信します。

### 送信先 API

すべて `Content-Type: application/json` と `X-Study21-Extension-Token: <接続コード>` ヘッダーを付けます。

| メソッド | パス | 用途 |
| --- | --- | --- |
| POST | `/api/user/browser-extension/register` | 端末登録（インストール時・起動時・設定保存時・接続テスト） |
| POST | `/api/user/browser-extension/heartbeat` | 稼働通知（5 分ごと） |
| POST | `/api/user/browser-extension/events` | 閲覧イベントの送信（最大 100 件／回） |

接続コードが未設定・誤っている場合は 401 を返します。そのときイベントは削除せずキューに残し、
接続コードを直せば次回の送信で登録されます。

応答は 2.1 の共通レスポンス形式（`{"success":true,"code":"OK","message":"...","data":{...}}`）と、
`data` を持たないフラットな形式の両方に対応しています（`data` があればその中の
`insertedCount` / `duplicateCount` / `skippedCount` を読みます）。`success` が `false` の応答は
HTTP 200 でも失敗として扱い、キューを保持します。

日時はすべて `isoNow()` で ISO 8601（タイムゾーンオフセット付き、例 `2026-06-27T10:05:30+09:00`）に
整形して送ります。

## 5. 機能 2: 単語帳（ローカル）

- ページ上で文字列を選択 → 右クリック → **「Study 2.1 単語帳に追加」** を選ぶと、単語帳ページが開き、
  選択した文字列と参照元 URL が入力欄に自動で入ります。
- 単語帳ページでは次の操作ができます。
  - 追加（英単語は必須。意味・メモ・登録元 URL は任意）
  - 検索（英単語・意味・メモ・登録元 URL の部分一致）
  - 削除
  - CSV エクスポート（列: 英単語 / 意味 / メモ / 登録元URL / 登録日時。Excel 用に BOM 付き UTF-8）
  - 登録件数の表示
- データは `chrome.storage.local` の **`study21.words`** にのみ保存され、**サーバーへは送信しません**。

## 6. 保存されるデータ（chrome.storage.local）

| キー | 内容 |
| --- | --- |
| `study21.apiBaseUrl` | API のベース URL |
| `study21.accessCode` | 接続コード |
| `study21.deviceName` | 端末名 |
| `study21.deviceId` | 端末識別子（初回生成後は固定） |
| `study21.recordingEnabled` | 記録の ON/OFF |
| `study21.queue` | 送信待ちイベントのキュー |
| `study21.lastSentAt` | 最終送信日時 |
| `study21.connectionStatus` | 接続状態（`unset` / `ok` / `error` とメッセージ） |
| `study21.words` | 単語帳のデータ |

閲覧セッション ID（`sessionId`）は `chrome.storage.session` に保持し、ブラウザを再起動すると新しくなります。

## 7. 困ったときは

| 症状 | 対処 |
| --- | --- |
| ポップアップが「未設定」 | 設定画面で接続コードを入力して保存してください |
| ポップアップが「エラー」 | メッセージを確認してください。401 の場合は接続コードが誤りか失効しています。発行し直して再設定してください |
| 「送信待ち」が減らない | API の URL とネットワーク（VPN・学内ネットワーク）を確認し、「接続テスト」を実行してください。接続が回復すると自動で再送されます |
| 記録されない | 設定画面の「閲覧履歴を記録する」が ON か確認してください。また `chrome://` や `file://` のページは対象外です |
| 設定を変えたのに反映されない | `chrome://extensions` で拡張機能の「更新」を押してください |

## 8. ファイル構成

```
extension/
├── manifest.json    拡張機能の定義（MV3）
├── background.js    閲覧履歴の収集・キュー・送信・端末登録・ハートビート・右クリックメニュー
├── popup.html/.js/.css   ツールバーのポップアップ（接続状態・送信待ち件数・最終送信時刻）
├── settings.html/.js/.css 設定画面（API URL・接続コード・端末名・記録 ON/OFF・接続テスト）
├── wordbook.html/.js/.css 単語帳（ローカル保存・CSV エクスポート）
├── icons/           icon16.png / icon48.png / icon128.png（2.0 版から継承）
└── README.md        このファイル
```

## 9. 開発メモ

- ビルド手順はありません。ファイルを編集したら `chrome://extensions` の「更新」を押すだけで反映されます。
- 構文チェック: `node --check background.js`（各 .js に対して実行できます）。
- イベント収集の一時停止は、設定画面のチェックを外すか、`chrome://extensions` で拡張機能自体を無効化してください。
